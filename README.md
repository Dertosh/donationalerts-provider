# DonationAlerts Provider — плагин OBS

Нативный плагин OBS Studio на C++ для Windows x64. Плагин должен запускать локальный API внутри OBS; отдельный Node.js-сервер не требуется.

> **Важно:** сейчас готов только начальный этап разработки: загрузка плагина, локальная страница управления и выпуск/отзыв временных ключей. Подключение OAuth DonationAlerts, получение донатов и целей, проверка ключа виджета и WebSocket-поток пока не реализованы. Пока эти функции не добавлены, плагин не передаёт реальные данные виджетам.

## Установка готового плагина

Для текущей сборки требуется **OBS Studio 32.2.2 x64**. Сборка для другой версии OBS и 32-битная версия не поддерживаются.

1. Полностью закройте OBS, в том числе из области уведомлений рядом с часами.
2. Получите файл `donationalerts-obs-provider.dll` из сборки проекта или релиза.
3. Откройте **PowerShell от имени администратора**. На Windows плагин устанавливается для всех пользователей в `%ProgramData%`.
4. Перейдите в папку проекта и выполните:

   ```powershell
   $pluginDir = Join-Path $env:ProgramData "obs-studio\plugins\donationalerts-obs-provider\bin\64bit"
   New-Item -ItemType Directory -Force -Path $pluginDir
   Copy-Item -LiteralPath ".\obs-plugin\build\Release\donationalerts-obs-provider.dll" -Destination $pluginDir
   ```

   Если DLL у вас в другой папке, укажите её полный путь в `Copy-Item`.
5. Запустите OBS. Если плагин загрузился, в меню **Инструменты** появится пункт **Open DonationAlerts Provider**.
6. Проверьте запуск в журнале OBS (**Справка → Файлы журнала → Просмотреть текущий журнал**). Там появятся адрес `http://127.0.0.1:4041/admin` и административный ключ. Ключ секретный — не публикуйте и не вставляйте его в виджеты.
7. Откройте адрес панели в браузере и введите административный ключ.

Чтобы удалить плагин, сначала закройте OBS, затем удалите папку `donationalerts-obs-provider` из `%ProgramData%\obs-studio\plugins`.

## Подготовка окружения разработки

Необязательно, если у вас уже есть готовая DLL. Для самостоятельной сборки нужны:

- OBS Studio **32.2.2 x64**;
- Visual Studio 2022 с компонентом «Разработка классических приложений на C++»;
- Windows SDK **10.0.26100**;
- CMake **3.28 или новее**;
- `curl.exe`.

Из корневой папки проекта запустите в PowerShell:

```powershell
.\tools\prepare-obs-sdk.ps1
```

Скрипт скачивает официальный архив исходников OBS, проверяет его SHA-256, настраивает CMake и собирает `libobs` и OBS Frontend API. Необязательный параметр `-Configuration Debug` собирает SDK в конфигурации Debug вместо Release. Исходники SDK и сборочные файлы сохраняются в игнорируемой папке `.obs-sdk`.

Затем соберите и проверьте плагин:

```powershell
cmake -S .\obs-plugin -B .\obs-plugin\build -G "Visual Studio 17 2022" -A "x64,version=10.0.26100.0"
cmake --build .\obs-plugin\build --config Release
ctest --test-dir .\obs-plugin\build -C Release --output-on-failure
```

Готовый файл появится здесь:

```text
obs-plugin\build\Release\donationalerts-obs-provider.dll
```

Вместо ручного копирования можно установить файл командой в **PowerShell от имени администратора**, находясь в корневой папке проекта:

```powershell
cmake --install .\obs-plugin\build --config Release --prefix "$env:ProgramData\obs-studio"
```

Перед установкой закройте OBS. CMake положит модуль в каталог плагинов OBS под `%ProgramData%`.

## Текущие возможности и ограничения

Плагин добавляет пункт **Инструменты → Open DonationAlerts Provider** и запускает HTTP API, привязанный только к `127.0.0.1:4041`. На текущем этапе доступны:

- `GET /health` — проверить запуск локального API;
- `GET /admin` — панель управления;
- `GET /api/widget-tokens` — список метаданных активных ключей;
- `POST /api/widget-tokens` — выпустить временный ключ;
- `POST /api/widget-tokens/revoke` — отозвать ключ.

Административные запросы требуют заголовок `X-Admin-Token`. Секрет временного ключа показывается только при выпуске; разрешены только read-only scope событий донатов, целей и опросов. Ключи хранятся в памяти и сбрасываются при закрытии OBS.

**Следующие необходимые этапы разработки:** OAuth DonationAlerts, получение профиля и истории донатов, аутентификация временных ключей при запросе данных, доставка событий донатов/целей/опросов через WebSocket. До реализации этих этапов панель выпускает ключи, но виджеты ещё не могут получать от плагина данные.

Не пробрасывайте локальный порт во внешнюю сеть. При ошибке загрузки проверьте, что OBS закрыт во время копирования, установлена правильная версия **OBS 32.2.2 x64**, DLL находится в `bin\64bit`, а журнал OBS не сообщает об отсутствующих зависимостях или занятом порте `4041`.
